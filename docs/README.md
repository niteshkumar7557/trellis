# Thread — documentation

**Thread** keeps a self-taught learner from abandoning a subject. It does four things and
deliberately nothing else: it makes a subject finite by telling you what you can skip; it
asks one question a day; it tells the difference between being busy and avoiding a topic;
and when you are stuck it makes the next step smaller instead of the message louder.

It never explains a concept. It hands you a prompt and you take that to your own AI.
